# R3 — 파이프라인

## 단계

```
S1 수집 ─G1─ S2 분석 ─G2─ S3 설계 ─G3─ S4 컨셉 ─G4─ S5 제작·검토
(1)          (2)          (3)          (4·5)         (6·7)
```

괄호 안 숫자는 `story-work.md`의 단계 번호입니다.

## 입출력

| 단계 | 입력 | 출력 |
|---|---|---|
| S1 수집 | 대상 화면, 키워드 | 레퍼런스 목록 (화면당 5개 이상, 링크 포함) |
| S2 분석 | 레퍼런스 목록, story-service | 반영 항목 목록 (항목마다 레퍼런스와 유저스토리 번호 연결) |
| S3 설계 | 반영 항목, design.md | 화면 설계 문서 (화면별 구성 요소와 컴포넌트명) |
| S4 컨셉 | 설계 문서 | Figma 키스크린 (화면당 390×844 프레임 1개) |
| S5 제작·검토 | 승인된 키스크린 | 토큰, 컴포넌트, 완성 화면, 위반 리포트 |

## 되돌아가는 곳

| 실패 | 복귀 |
|---|---|
| G2 | S2 |
| G3 | S3 |
| G4 반려 | S3 |
| S5 위반 | S5 |
| 같은 게이트 3번 연속 실패 | 멈추고 사람에게 질문 |

## 7단계 검토

- 허용값 위반: 판정 스크립트가 셈
- 목록으로 셀 수 없는 규칙: 읽기전용 판정 에이전트가 판정
