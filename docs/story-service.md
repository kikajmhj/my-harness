# 허들링 앱 — 서비스 유저스토리 (MVP 1차)

> 출처: `docs/prd.md` · 범위: MVP 1차 (Phase 2·3 제외)

## 유저스토리

| # | 유저스토리 | PRD 근거 |
|---|---|---|
| 1 | **비회원·무료 회원**이 공개 학습자료를 카테고리별로 둘러보고, 유료 자료는 미리보기로 확인한다 | §3-1, §6-1, §7-1~2 |
| 2 | **유료 회원**이 강의자료·템플릿·스킬/프롬프트 카드를 한곳에서 찾아 복사·다운로드한다 | §3-2, §6-2, §6-3 |
| 3 | **유료 회원**이 이번 달 미션을 확인하고 산출물을 제출한다 (상태: `작성 중` / `제출 완료`) | §3-3, §6-4, §9 결정 4 |
| 4 | **판매 승인 회원**이 자기 자산을 판매 신청하고 검수 상태를 확인한다 (MVP 최종 상태: `승인됨`) | §3-4, §6-5, §7-4, §9 결정 2·5 |
| 5 | **운영자**가 판매 신청된 자산을 체크리스트로 검수해 승인 / 수정 요청 / 반려한다 | §3-6, §6-7, §7-5 |

## 이 서비스에서 어기면 안 되는 것

| # | 규칙 | PRD 근거 |
|---|---|---|
| A | 판매 자산은 반드시 운영자 검수를 통과해야 하며, 판매 신청은 판매 승인 회원만 할 수 있다 | §14, §9 결정 2, §6-7 |
| B | 개인정보·고객정보·회사기밀·타인의 저작물은 판매 자산에 포함될 수 없다 | §14, §6-7 판매 기준 6·7 |

## 범위에서 제외한 것

- 구매자 스토리 (§3-5) — Phase 2
- 허들링 픽 노출, 판매 중 / 판매 중지 상태 — Phase 2
- 판매 수익 확인, 결제·정산 — Phase 3
- 미션 피드백 — MVP 제외 (다음 단계)
