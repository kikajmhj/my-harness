# R8 — 검증과 리뷰

## 1. 판정 스크립트 자체 시험 (하네스를 쓰기 전)

- `tests/fixtures/`에 게이트마다 통과 1개, 실패 1개
- 추가로 ★A 위반 샘플(`role: seller` 누락), ★B 위반 샘플(`010-1234-5678` 포함)
- 샘플 ≥ 10개, 예상 결과와 실제 결과가 전부 일치해야 통과

## 2. 폴더 경계 검사

- `scripts/check_scope.py`: 에이전트를 부르기 전과 후의 파일 해시 비교
- 자기 폴더 밖에서 바뀐 파일 = 0
- 예외: `design/s5-report.json` (판정 스크립트가 생성)

## 3. 시험 실행

- 대상 화면: 홈, 내 자산 (내 자산으로 ★A를 실제로 시험)
- 완료 기준은 `r2-purpose.md`와 같음

## 4. 리뷰

- 본인: Figma 프레임과 `s5-report.json`을 보고 손으로 했을 때와 비교해 쓸 만한지 판단
- 별도 서브에이전트: 스크립트, 에이전트 정의, `CLAUDE.md`가 R0~R7 결정과 어긋나는 곳을 목록으로 뽑음
- 어긋난 곳 = 0이면 완료
