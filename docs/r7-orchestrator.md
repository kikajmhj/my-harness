# R7 — 오케스트레이터

## 구성

- 오케스트레이터: 프로젝트 루트 `CLAUDE.md`를 읽는 메인 세션
- 서브에이전트: `.claude/agents/{researcher,planner,designer,judge}.md` (frontmatter로 쓸 수 있는 도구 제한)

## CLAUDE.md 범위 (150줄 이하)

1. 문서 지도
2. 자연어 트리거
3. 단계 순서
4. 게이트 호출 규칙
5. 금지 사항
6. 보고 형식

세부 내용은 `docs/r*.md` 링크로만 둔다.

## 금지 사항 (셀 수 있는 형태)

- `state.json` 말고 오케스트레이터가 직접 편집한 파일 = 0
- 게이트 `pass` 기록 없이 다음 단계 에이전트 호출 = 0
- G4 승인 기록 없이 S5 호출 = 0
- 에이전트가 자기 폴더 밖에서 바꾼 파일 = 0 (R8 스크립트로 검사)

## 보고 형식 (게이트마다 한 줄)

- pass: `G2 pass — 반영 항목 9개, 연결 누락 0개 → S3 시작`
- fail: `G2 fail (2/3) — 연결 누락 2개: R-03, R-07 → S2 재시도`
